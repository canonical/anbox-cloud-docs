# 1.30.2

These release notes cover new features and changes in Anbox Cloud 1.30.2.

Anbox Cloud 1.30.2 is a patch release. To understand minor and patch releases, see {ref}`Release notes <ref-release-notes>`.

Please see the {ref}`Component versions <ref-component-versions>` for a list of updated components.

## Requirements

See the {ref}`Requirements <ref-requirements>` for details on general and deployment specific requirements to run Anbox Cloud.

## New features & improvements

- The Android WebView has been updated to [154.0.8037.21](https://chromereleases.googleblog.com/2026/09/chrome-for-android-update_01390050711.html).

## Deprecations and removed functionality

There are no deprecations or removal of support for features in this release.

## Known issues

See our [open bugs in Launchpad](https://bugs.launchpad.net/anbox-cloud/+bugs?field.searchtext=&orderby=-importance&field.status%3Alist=NEW&field.status%3Alist=CONFIRMED&field.status%3Alist=TRIAGED&field.status%3Alist=INPROGRESS&field.status%3Alist=INCOMPLETE_WITH_RESPONSE&field.status%3Alist=INCOMPLETE_WITHOUT_RESPONSE&assignee_option=any&field.assignee=&field.bug_reporter=&field.bug_commenter=&field.subscriber=&field.structural_subscriber=).

## Bug fixes

- [LP 2157766](https://bugs.launchpad.net/anbox-cloud/+bug/2157766) Video playback showed graphics tearing on the GPU instance during the first launch of the game Seaside Escape.
- [LP 2163752](https://bugs.launchpad.net/anbox-cloud/+bug/2163752) The `prepare-node-script` generated by `anbox-cloud-appliance` failed to run on the HWE 24.04 kernel.
- [LP 2164565](https://bugs.launchpad.net/anbox-cloud/+bug/2164565) The stream agent could lose the OpenFGA authorization race after creating an instance.
- [LP 2165867](https://bugs.launchpad.net/anbox-cloud/+bug/2165867) The games, Project Makeover, crashed on first startup, though the crash did not recur on subsequent launches.
- [LP 2167674](https://bugs.launchpad.net/anbox-cloud/+bug/2167674) VHAL property values showed as `None` in the right panel when joining an instance created from an AAOS Cuttlefish image.
- [LP 2164700](https://bugs.launchpad.net/anbox-cloud/+bug/2164700) A goroutine panic could occur during a worker operation.
- [LP 2166133](https://bugs.launchpad.net/anbox-cloud/+bug/2166133) Android init repeatedly triggered `numbat-net` every 10 seconds, spamming the console log.
- [LP 2161279](https://bugs.launchpad.net/anbox-cloud/+bug/2161279) Private bug
- [LP 2165965](https://bugs.launchpad.net/anbox-cloud/+bug/2165965) Private bug
