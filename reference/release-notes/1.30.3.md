# 1.30.3

These release notes cover bug fixes and security updates in Anbox Cloud 1.30.3.

Anbox Cloud 1.30.3 is a patch release. To understand minor and patch releases, see {ref}`Release notes <ref-release-notes>`.

Please see the {ref}`Component versions <ref-component-versions>` for a list of updated components.

## Requirements

See the {ref}`Requirements <ref-requirements>` for details on general and deployment specific requirements to run Anbox Cloud.

## New features & improvements

- The Android WebView has been updated to [156.0.8078.39](https://chromereleases.googleblog.com/2026/10/chrome-for-android-update_02125536954.html).

## Deprecations and removed functionality

There are no deprecations or removal of support for features in this release.

## Known issues

See our [open bugs in Launchpad](https://bugs.launchpad.net/anbox-cloud/+bugs?field.searchtext=&orderby=-importance&field.status%3Alist=NEW&field.status%3Alist=CONFIRMED&field.status%3Alist=TRIAGED&field.status%3Alist=INPROGRESS&field.status%3Alist=INCOMPLETE_WITH_RESPONSE&field.status%3Alist=INCOMPLETE_WITHOUT_RESPONSE&assignee_option=any&field.assignee=&field.bug_reporter=&field.bug_commenter=&field.subscriber=&field.structural_subscriber=).
