# ams.amc project create

Create a new project in AMS

## Synopsis

Create a new project in AMS.

Use this command to create a project to organize instances.


```
ams.amc project create <name> [flags]
```

## Examples

```
$ amc project create team-a --description "Project for team A"
```

## Options

```
  -d, --description string   A description for the project
  -h, --help                 help for create
```
