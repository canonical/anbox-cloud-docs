# ams.amc project set

Update fields for a project

## Synopsis

Update fields for a project.

Update specific fields for an existing project.
The following fields can be updated: description

```
ams.amc project set <name> <field> <value> [flags]
```

## Examples

```
$ amc project set team-a description "Project for team A"
```

## Options

```
  -h, --help   help for set
```
